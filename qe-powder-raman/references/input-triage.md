# 固体粉末拉曼请求的预检与回复指南

在生成输入或承诺结果前，依次核对结构、体系、方法、参数和交付物。回复时说明实际发现的问题、它影响的步骤，以及用户可以补充或改用的最小信息。预检可以提供诊断；只有完成计算并通过产物校验后，才能报告计算结果。

| 处理 | 使用条件 |
|---|---|
| **补充信息** | 缺少结构、相别或关键实验条件。能先完成结构与环境预检时，先做预检。 |
| **修正后重试** | 参数格式、文件路径、赝势映射或阶段产物有明确错误。指出具体文件或参数。 |
| **停止当前路线** | 请求的材料或物理量超出所用方法。给出可用路线或可交付的诊断。 |
| **带警告继续** | 计算可以运行，但存在待确认的磁性、对称性、数值收敛或结构稳定性问题。保留具体证据与限制。 |

## 1. 结构输入

| 常见输入 | 判断与回复 |
|---|---|
| 只给化学式、材料商品名、谱图或 PDF | 同一化学式可能对应多个晶相。请提供 CIF、POSCAR 或可追溯的结构编号并确认晶相。若已有多个候选结构，核查后再选定计算对象。 |
| CIF 有部分占位、混占、空位平均或统计无序 | 暂停生成 QE 输入。请提供有明确原子占位的有序构型，或先约定具代表性的超胞。记录所选构型，避免用单个构型代表全部无序。 |
| 晶胞退化、坐标非有限、近邻原子重叠或单位疑似错配 | 指出出错的晶胞、坐标或原子对。请核对晶格和坐标单位、分数/笛卡尔坐标标识及对称展开。 |
| 不正确的空间群、原胞容差或六方角数值噪声 | 比较原结构、精化结构和 QE 识别的对称性。若精化改变原子数而回退，报告原因。遇到疑似物理畸变时保留原结构，先核对来源和容差。 |
| 多相、掺杂或缺陷样品 | 要求各相或缺陷的结构与浓度。可以分别计算模型；只有给定可信比重与强度模型后才讨论混合谱。 |

## 2. 体系和方法适用性

| 请求或信号 | 判断与回复 |
|---|---|
| 三维周期、非磁、闭壳层有隙晶体 | 属于本工作流的目标体系。可以先预检，再用 SCF 能级核对采样网格上的带隙。当前 CLI 以测得带隙 ≤ 0.05 eV 为停算阈值。这个阈值是流程判据，粗网格的正带隙仍需收敛验证。 |
| 金属、半金属、明确小带隙或用 smearing 强行收敛 | 停止当前固定占据 Γ 点拉曼路线。不要用固定占据掩盖金属性。旧日志缺少空带能级时，标记带隙未知，优先补跑 SCF。 |
| 含潜在磁性元素，或用户要求磁有序、非共线、SOC、Hubbard U | 元素提示本身只触发核查。已知必须描述磁序或相关效应时，当前拉曼路线超出适用范围。保留用户的方法要求，另选适用方案。 |
| 单层、表面、显著真空、纳米颗粒、分子、非晶、液体 | 需要对应维度或统计系综的方法；当前工作流的体相介电响应和粉末近似不适用。体相层状晶体可带警告运行，涉及层间软模或 LO 时说明边界条件。 |
| PBE/PBEsol、PAW/USPP、混合赝势、DFT+U、杂化/meta-GGA 或 GPU 拉曼 | 当前已验证拉曼路线为 CPU、NC + LDA（PZ）。核对 UPF 头中的元素、类型、XC 及选中路径。PBE/PBEsol 不能在本路线生成 Raman 张量。若安装版本提供 `--no-lraman` 并明确支持所选 NC 赝势，可另作声子/IR，先确认这符合交付要求。 |
| 缺元素赝势，或某元素匹配多个 UPF | 列出元素和候选文件，要求提供兼容 UPF 或整理专用目录。严禁按名称猜测元素或自行混用 XC。 |

这些边界适用于本技能的 Γ 点二阶响应设置。QE 的其他声子任务可能有不同支持范围。见 [QE `ph.x` 输入说明](https://www.quantum-espresso.org/Doc/INPUT_PH.html) 和 [本技能兼容性说明](qe_compatibility.md)。

## 3. 参数与运行顺序

| 参数或操作 | 判断与回复 |
|---|---|
| `kpt_grid`、`kpt_density` 与声子 `q` 混用 | SCF k 网格需要三个正整数或有效的密度设置。声子计算在 Γ，`lo_to_directions` 则是 `dynmat.x` 非解析项的笛卡尔传播方向。显式 k 网格覆盖密度设置。 |
| 使用零向量、错误维数、NaN 或把晶轴指标直接当 LO 笛卡尔坐标 | LO 方向必须是三个有限实数组成的非零向量，按计算晶胞换算。没有 LO 方向时默认输出 Γ 点 TO 结果。缺有效电荷或介电张量时先检查 `ph.x` 输出。见 [QE `dynmat.x` 输入说明](https://www.quantum-espresso.org/Doc/INPUT_DYNMAT.html)。 |
| `ecutwfc` / `ecutrho` 单位不明；把默认截断能、粗网格当作已收敛 | 用 Ry 核对输入并记录有效值，分别收敛截断能、k 网格和 `tr2_ph`，比较峰位、活性与介电响应。SCF 或 DFPT 日志显示收敛只证明当前输入的迭代完成。 |
| `conv_thr` / `tr2_ph` 非有限、≤ 0 或 ≥ 1；MPI/OMP 不是正整数 | 指明无效字段与允许范围。换成可解析的正值后再生成输入；资源和 MPI 启动器按本机环境设置。 |
| `FWHM ≤ 0`、负温度、激光波长 ≤ 0 或单位写成 eV | FWHM 用 cm⁻¹ 且大于零，温度用 K 且非负，激光用正值 nm。Stokes 模式需有正谱移，且谱移小于激光波数。FWHM 用于绘图展宽。 |
| 未收敛弛豫、改变参数后复用旧 SCF、复用其他 run 的矩阵 | 保留原始日志。只有收敛弛豫的末态可用于重建 SCF。区分项目 `outdir` 与 QE `qe_outdir`，确认 `pw.x` 与 `ph.x` 指向同一组当前产物；用 `--skip-existing` 按阶段校验后续跑。 |
| `ph.x` 的 `set_irr_sym_new` 报 `wrong representation` | 先核对 CIF、精化结果、QE 版本和日志。问题确认出在声子模式对称性分析后，可用干净目录和 `ph_search_sym: false` 单独复验，记录此变更、成本和对模式分类的影响。其他 QE 错误按实际日志处理。 |

## 4. 交付与解释边界

| 用户要求或输出 | 回应 |
|---|---|
| 二阶/多声子、有限 q 色散、共振 Raman、偏振单晶或择优取向 | 当前默认产物是 Γ 点一级、非共振、谐波粉末谱。先确认目标是完整谱、峰指认还是单项张量；为超出范围的目标另选方法。 |
| 绝对散射强度、实验级线宽、温度引起的峰移、由单条模拟谱确定物相比例 | 当前活性和相对 Stokes 谱用于同近似下比较。温度和波长改变 Stokes 权重，展宽参数控制绘图线形。实验对照记录激光、温度、相别、波数单位、归一化和峰分配的不确定性。 |
| 希望直接把 x/y/z 的 LO 谱平均成极性粉末谱 | 可以交付逐方向 LO 和默认 TO。粉末方向积分还需要确定传播权重和散射几何，当前流程不自动提供。 |
| mode 表无拉曼列、空谱或强度低 | 先区分计算完成且张量已验证的零活性、显式关闭 `lraman`、张量缺失或阈值滤掉的模式。只有第一种支持“本次方法下无一级拉曼活性”的结论。 |
| 负频率、报告 `warning`、用户要求把峰强制画成正值 | 保留虚频及模式编号，检查声学模式、ASR、结构弛豫、截断能和 k 网格。显著光学虚频需作为待验证的结构或数值问题报告。绘谱筛除虚频，不把负频率取绝对值冒充物理峰。 |
| 缺日志、`JOB DONE`、请求的 LO 结果或 `3N` 完整模式 | 标记未完成并说明缺失阶段。保留诊断产物，避免把旧谱、部分结果或仅存在的报告当成成功。 |
| 报告中的展宽、激光波长或谱图文件与最近一次绘谱不一致 | 核对 `spectrum_manifest.json` 的实际设置和文件清单。如果模式表已改变或没有可核验的绘谱记录，重新执行 `spectrum` 后再生成报告。 |

## 可直接使用的回复

- **缺结构**：“目前有化学式，没有确定晶相。请提供 CIF/POSCAR 或结构编号和相别。我可以先核对原子占位、晶胞和赝势覆盖。”
- **方法不支持**：“你指定了 PBE Raman。当前验证的 QE Raman 路线需要 NC + LDA。若目标必须保留 PBE，请改用能生成 PBE Raman 张量的方法；如果只需要声子或 IR，我可以先确认安装版本的支持范围。”
- **有隙证据不足**：“这份 SCF 日志没有空带能级，目前无法确认带隙。先重跑含空带的 SCF，并检查 k 网格，再决定是否进入 `ph.x`。”
- **弛豫未收敛**：“弛豫达到了步数上限，尚未得到可用于下游的收敛结构。已保留原 SCF 输入和日志。下一次先核对力、应力与步数设置。”
- **已出谱但有虚频**：“计算生成了谱图与模式表，其中有 N 支光学虚频，频率和编号已列在报告里。当前谱仅用于诊断；稳定结构的峰位还需弛豫和收敛复核。”

已有 QE 日志时先看 [常见运行失败与处理](failure_modes.md)。解释强度、选择定则和展宽时参照 [粉末拉曼理论](raman_theory.md)。
